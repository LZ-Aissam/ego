# EGO — Livraison D « Crew » Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer la page « Crew bientôt » par un vrai espace social : classement (XP / série / force), liste des membres et profils publics, groupes à code d'invitation.

**Architecture:** Deux classes de domaine dans `App\Crew` — `CrewService` (cycle de vie des groupes, autorisations, limites) et `Leaderboard` (classement calculé à la volée depuis `xp_events`, `users` et `personal_records`). Trois composants Livewire pleine page (`CrewPage`, `MemberPage`, `GroupPage`) et un contrôleur pour le lien d'invitation. Aucune table précalculée, aucune tâche planifiée.

**Tech Stack:** Laravel 12, Livewire 3, Alpine, Tailwind 4 (composants `x-sys.*`), Pest 4 sur MariaDB `ego_testing`.

**Spec:** `docs/superpowers/specs/2026-10-06-ego-crew-design.md`

## Global Constraints

- Base MariaDB partout (dev : `ego` sur 127.0.0.1:3307 ; tests : `ego_testing`), moteur InnoDB.
- Fuseau `Europe/Paris` (config `app.timezone`) ; la semaine commence le lundi 00:00, le mois le 1er 00:00.
- Textes en français avec accents ; le système parle sous le nom « TON EGO » ; composants `x-sys.window`, `x-sys.button`, `x-sys.field`, `x-sys.label`, classes `sys-row`, `sys-chip`, `sys-chip--active`, `sys-num`, `sys-label`, `sys-error`.
- Nom de groupe : 2 à 30 caractères. Couleurs : `ice`, `cyan`, `violet`, `gold`, `red`, `green`. Code : 6 caractères parmi `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`.
- 10 groupes au plus par membre ; 10 essais de code par minute et par joueur.
- Messages exacts : « Code inconnu. », « Tu fais déjà partie de 10 groupes. », « Trop d'essais, réessaie dans une minute. », « Aucun chasseur classé pour l'instant. », « Gagne de l'XP pour entrer au classement ».
- Force : `bench` → `bench-press`, `squat` → `back-squat`, `deadlift` → `deadlift` ; ratio `best_e1rm_kg ÷ weight_kg` arrondi à 0,01.
- Valeurs affichées : `1 240 XP`, `12 j`, `×1,35`.
- Profil public : jamais date de naissance, âge, poids, taille, IMC, historique, pénalités, quêtes ratées.
- Non-membre sur une page de groupe → 404 ; action de créateur par un autre → 403.
- Pas de boîte de dialogue navigateur (`confirm()`), confirmation intégrée à l'interface.

5. Profil public d'un joueur sans programme, sans record, sans titre : la page s'affiche avec des états vides (test Task 6).

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;

class Crew extends Model
{
    public const COLORS = ['ice' => '#5ad8ff', 'cyan' => '#22d3ee', 'violet' => '#a78bfa', 'gold' => '#ffb547', 'red' => '#ff4d6d', 'green' => '#34d399'];

    public const COLOR_NAMES = ['ice' => 'Glace', 'cyan' => 'Cyan', 'violet' => 'Violet', 'gold' => 'Or', 'red' => 'Rouge', 'green' => 'Vert'];

    private const CODE_ALPHABET = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';

    protected $fillable = ['name', 'color', 'code', 'owner_id'];

    public function owner(): BelongsTo
    {
        return $this->belongsTo(User::class, 'owner_id');
    }

    public function members(): BelongsToMany
    {
        return $this->belongsToMany(User::class)->withPivot('joined_at');
    }

    public function isOwnedBy(User $user): bool
    {
        return $this->owner_id === $user->id;
    }

    public function hasMember(User $user): bool
    {
        return $this->members()->whereKey($user->id)->exists();
    }

    public function hex(): string
    {
        return self::COLORS[$this->color] ?? self::COLORS['ice'];
    }

    public static function generateCode(): string
    {
        do {
            $code = '';
            for ($i = 0; $i < 6; $i++) {
                $code .= self::CODE_ALPHABET[random_int(0, strlen(self::CODE_ALPHABET) - 1)];
            }
        } while (self::where('code', $code)->exists());

        return $code;
    }

    public static function normalizeCode(string $code): string
    {
        return strtoupper(preg_replace('/[\s\-]+/', '', $code));
    }
}
```

```php
<?php

namespace App\Crew;

use App\Models\Crew;
use App\Models\User;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\RateLimiter;
use Illuminate\Validation\Rule;
use Illuminate\Validation\ValidationException;

final class CrewService
{
    public const MAX_CREWS = 10;

    public const MAX_JOIN_ATTEMPTS = 10;

    public function create(User $user, string $name, string $color): Crew
    {
        $data = $this->validated($name, $color);
        $this->ensureRoom($user, 'name');

        return DB::transaction(function () use ($user, $data) {
            $crew = Crew::create([...$data, 'code' => Crew::generateCode(), 'owner_id' => $user->id]);
            $crew->members()->attach($user->id, ['joined_at' => now()]);

            return $crew;
        });
    }

    public function join(User $user, string $code): Crew
    {
        $key = 'crew-join:'.$user->id;
        if (RateLimiter::tooManyAttempts($key, self::MAX_JOIN_ATTEMPTS)) {
            throw ValidationException::withMessages(['code' => 'Trop d\'essais, réessaie dans une minute.']);
        }
        RateLimiter::hit($key, 60);

        $crew = Crew::firstWhere('code', Crew::normalizeCode($code));
        if (! $crew) {
            throw ValidationException::withMessages(['code' => 'Code inconnu.']);
        }

        if ($crew->hasMember($user)) {
            return $crew;
        }

        $this->ensureRoom($user, 'code');
        $crew->members()->attach($user->id, ['joined_at' => now()]);

        return $crew;
    }

    public function leave(User $user, Crew $crew): void
    {
        DB::transaction(function () use ($user, $crew) {
            $crew->members()->detach($user->id);

            if (! $crew->isOwnedBy($user)) {
                return;
            }

            $next = $crew->members()->orderBy('crew_user.joined_at')->orderBy('users.id')->first();
            $next ? $crew->update(['owner_id' => $next->id]) : $crew->delete();
        });
    }

    public function update(User $user, Crew $crew, string $name, string $color): void
    {
        $this->authorizeOwner($user, $crew);
        $crew->update($this->validated($name, $color));
    }

    public function regenerateCode(User $user, Crew $crew): string
    {
        $this->authorizeOwner($user, $crew);
        $crew->update(['code' => Crew::generateCode()]);

        return $crew->code;
    }

    public function kick(User $owner, Crew $crew, User $member): void
    {
        $this->authorizeOwner($owner, $crew);

        if ($member->id !== $owner->id) {
            $crew->members()->detach($member->id);
        }
    }

    public function delete(User $user, Crew $crew): void
    {
        $this->authorizeOwner($user, $crew);
        $crew->delete();
    }

    /** @return array{name: string, color: string} */
    private function validated(string $name, string $color): array
    {
        return validator(['name' => trim($name), 'color' => $color], [
            'name' => ['required', 'string', 'min:2', 'max:30'],
            'color' => ['required', Rule::in(array_keys(Crew::COLORS))],
        ], [
            'name.required' => 'Donne un nom à ton groupe.',
            'name.min' => 'Le nom doit faire au moins 2 caractères.',
            'name.max' => 'Le nom doit faire au plus 30 caractères.',
            'color.*' => 'Choisis une couleur d\'emblème.',
        ])->validate();
    }

    private function ensureRoom(User $user, string $field): void
    {
        if ($user->crews()->count() >= self::MAX_CREWS) {
            throw ValidationException::withMessages([$field => 'Tu fais déjà partie de 10 groupes.']);
        }
    }

    private function authorizeOwner(User $user, Crew $crew): void
    {
        abort_unless($crew->isOwnedBy($user), 403);
    }
}
```

```php
<?php

namespace App\Crew;

use App\Models\Crew;
use App\Models\Exercise;
use App\Models\PersonalRecord;
use App\Models\User;
use App\Models\XpEvent;
use Illuminate\Support\Carbon;
use Illuminate\Support\Collection;

final class Leaderboard
{
    public const METRICS = ['xp', 'streak', 'force'];

    public const PERIODS = ['week', 'month', 'all'];

    public const LIFTS = ['bench' => 'bench-press', 'squat' => 'back-squat', 'deadlift' => 'deadlift'];

    /** @return Collection<int, array{user: User, value: int|float, rank: int}> */
    public function rank(string $metric, string $period = 'week', string $lift = 'bench', ?Crew $crew = null): Collection
    {
        $users = $crew ? $crew->members()->get() : User::all();

        $values = match ($metric) {
            'xp' => $this->xp($users, $period),
            'streak' => $users->mapWithKeys(fn (User $u) => [$u->id => (int) $u->streak_days]),
            'force' => $this->force($users, $lift),
        };

        $rows = $users->filter(fn (User $u) => $values->has($u->id))
            ->map(fn (User $u) => ['user' => $u, 'value' => $values[$u->id]])
            ->sort(fn ($a, $b) => [$b['value'], $a['user']->first_name, $a['user']->id] <=> [$a['value'], $b['user']->first_name, $b['user']->id])
            ->values();

        $previous = null;
        $rank = 0;

        return $rows->map(function (array $row, int $i) use (&$previous, &$rank) {
            if ($previous === null || $row['value'] != $previous) {
                $rank = $i + 1;
            }
            $previous = $row['value'];

            return [...$row, 'rank' => $rank];
        });
    }

    public static function format(string $metric, int|float $value): string
    {
        return match ($metric) {
            'xp' => number_format($value, 0, ',', ' ').' XP',
            'streak' => $value.' j',
            'force' => '×'.number_format($value, 2, ',', ' '),
        };
    }

    private function xp(Collection $users, string $period): Collection
    {
        if ($period === 'all') {
            return $users->mapWithKeys(fn (User $u) => [$u->id => (int) $u->xp_total]);
        }

        $since = $period === 'month' ? Carbon::now()->startOfMonth() : Carbon::now()->startOfWeek(Carbon::MONDAY);
        $totals = XpEvent::whereIn('user_id', $users->modelKeys())->where('created_at', '>=', $since)
            ->groupBy('user_id')->selectRaw('user_id, SUM(amount) AS total')->pluck('total', 'user_id');

        return $users->mapWithKeys(fn (User $u) => [$u->id => (int) ($totals[$u->id] ?? 0)]);
    }

    private function force(Collection $users, string $lift): Collection
    {
        $exerciseId = Exercise::where('slug', self::LIFTS[$lift] ?? self::LIFTS['bench'])->value('id');
        $records = PersonalRecord::where('exercise_id', $exerciseId)->whereIn('user_id', $users->modelKeys())->pluck('best_e1rm_kg', 'user_id');

        return $users->filter(fn (User $u) => $u->weight_kg > 0 && $records->has($u->id))
            ->mapWithKeys(fn (User $u) => [$u->id => round((float) $records[$u->id] / $u->weight_kg, 2)]);
    }
}
```

```php
<?php

namespace App\Livewire\Crew;

use App\Crew\CrewService;
use App\Crew\Leaderboard;
use App\Models\Crew;
use App\Models\User;
use Livewire\Attributes\Title;
use Livewire\Attributes\Url;
use Livewire\Component;

#[Title('Crew')]
class CrewPage extends Component
{
    public const TABS = ['classement', 'membres', 'groupes'];

    public const TOP = 50;

    #[Url]
    public string $tab = 'classement';

    #[Url]
    public string $metric = 'xp';

    #[Url]
    public string $period = 'week';

    #[Url]
    public string $lift = 'bench';

    #[Url(as: 'groupe')]
    public ?int $group = null;

    public string $search = '';

    public string $newName = '';

    public string $newColor = 'ice';

    public string $joinCode = '';

    public function mount(): void
    {
        $this->sanitize();
    }

    public function updated(): void
    {
        $this->sanitize();
    }

    private function sanitize(): void
    {
        $this->tab = in_array($this->tab, self::TABS, true) ? $this->tab : 'classement';
        $this->metric = in_array($this->metric, Leaderboard::METRICS, true) ? $this->metric : 'xp';
        $this->period = in_array($this->period, Leaderboard::PERIODS, true) ? $this->period : 'week';
        $this->lift = array_key_exists($this->lift, Leaderboard::LIFTS) ? $this->lift : 'bench';
        if ($this->group !== null && ! auth()->user()->crews()->whereKey($this->group)->exists()) {
            $this->group = null;
        }
    }

    public function createCrew(CrewService $crews)
    {
        $crew = $crews->create(auth()->user(), $this->newName, $this->newColor);

        return $this->redirectRoute('crew.group', $crew);
    }

    public function joinCrew(CrewService $crews)
    {
        $crew = $crews->join(auth()->user(), $this->joinCode);

        return $this->redirectRoute('crew.group', $crew);
    }

    public function render(Leaderboard $board)
    {
        $me = auth()->user();
        $myCrews = $me->crews()->withCount('members')->orderBy('name')->get();
        $data = ['me' => $me, 'myCrews' => $myCrews];

        if ($this->tab === 'classement') {
            $rows = $board->rank($this->metric, $this->period, $this->lift, $myCrews->firstWhere('id', $this->group));
            $data['rows'] = $rows->take(self::TOP);
            $mine = $rows->first(fn ($r) => $r['user']->id === $me->id);
            $data['pinned'] = $mine && $mine['rank'] > 0 && ! $data['rows']->contains(fn ($r) => $r['user']->id === $me->id) ? $mine : null;
        }

        if ($this->tab === 'membres') {
            $needle = mb_strtolower(trim($this->search));
            $data['members'] = User::orderBy('first_name')->get()
                ->filter(fn (User $u) => $needle === '' || str_contains(mb_strtolower($u->first_name), $needle))->values();
        }

        return view('livewire.crew.crew-page', $data);
    }
}
```

```php
<?php

namespace App\Livewire\Crew;

use App\Crew\CrewService;
use App\Models\Crew;
use App\Models\User;
use Livewire\Attributes\Locked;
use Livewire\Attributes\Title;
use Livewire\Component;

#[Title('Groupe')]
class GroupPage extends Component
{
    #[Locked]
    public int $crewId;

    public string $name = '';

    public string $color = 'ice';

    public bool $confirmingDelete = false;

    public function mount(Crew $crew): void
    {
        abort_unless($crew->hasMember(auth()->user()), 404);
        $this->crewId = $crew->id;
        $this->name = $crew->name;
        $this->color = $crew->color;
    }

    private function crew(): Crew
    {
        $crew = Crew::find($this->crewId);
        abort_unless($crew && $crew->hasMember(auth()->user()), 404);

        return $crew;
    }

    public function save(CrewService $crews): void
    {
        $crews->update(auth()->user(), $this->crew(), $this->name, $this->color);
    }

    public function regenerate(CrewService $crews): void
    {
        $crews->regenerateCode(auth()->user(), $this->crew());
    }

    public function kick(int $userId, CrewService $crews): void
    {
        $crew = $this->crew();
        abort_unless($crew->isOwnedBy(auth()->user()), 403);     // droits d'abord : un membre ne sonde pas les identifiants
        $member = User::find($userId);
        abort_unless($member !== null, 404);
        $crews->kick(auth()->user(), $crew, $member);
    }

    public function askDelete(): void
    {
        abort_unless($this->crew()->isOwnedBy(auth()->user()), 403);
        $this->confirmingDelete = true;
    }

    public function delete(CrewService $crews)
    {
        $crews->delete(auth()->user(), $this->crew());

        return $this->redirectRoute('community', ['tab' => 'groupes']);
    }

    public function leave(CrewService $crews)
    {
        $crews->leave(auth()->user(), $this->crew());

        return $this->redirectRoute('community', ['tab' => 'groupes']);
    }

    public function render()
    {
        $crew = $this->crew();

        return view('livewire.crew.group-page', [
            'crew' => $crew,
            'members' => $crew->members()->orderBy('crew_user.joined_at')->orderBy('users.id')->get(),
            'isOwner' => $crew->isOwnedBy(auth()->user()),
            'inviteUrl' => route('crew.join', $crew->code),
        ]);
    }
}
```
